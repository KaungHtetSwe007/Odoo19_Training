Myanmar NRC

Myanmar NRC data and contact fields for Odoo

Myanmar NRC adds NRC number, state code, township, and township code information to Odoo Contacts. It also loads Myanmar state, region, and township data for NRC-related records.

Contact NRC Fields

Add NRC number and township information directly on partner records.

Township Data

Maintain township records linked with Myanmar states and regions.

Main Features

  • Load Myanmar NRC state, region, and township data.
  • Add township records with codes.
  • Add NRC number, state code, township, and township code on contacts.
  • Provide menu entries for township maintenance.
  • Support translated township names and codes.
