Myanmar NRC
===========

Myanmar NRC adds Myanmar NRC related data and fields to Odoo Contacts.

Features
========

* Load Myanmar state, region, and township NRC data.
* Add township records linked to states.
* Add NRC number, township, state code, and township code fields on contacts.
* Provide menu entries to maintain township data.
* Support translated township names and codes.

Configuration
=============

Install the module. The Myanmar NRC data is loaded automatically.

Usage
=====

Open a contact and fill in the NRC fields. Use the township menu to review or
maintain township data when needed.
