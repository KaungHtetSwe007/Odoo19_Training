# Form Required Display

Improve required field visual feedback on forms.

## Module information

- Technical name: `ica_form_required_display`
- Version: `19.0.1.0.0`
- Category: Technical
- License: LGPL-3
- Author: Agga, IdeaCode Academy
- Dependencies: `web`

## Installation

1. Add this repository to the Odoo addons path.
2. Update the Apps list.
3. Search for **Form Required Display** and select **Activate**.

## Configuration and use

Install the module, then open the related Odoo application to configure and use its features. Access depends on the standard Odoo security groups declared by the module.
